# Changelog

All notable changes to circle-packs are listed here, newest first. Versions start at 0.1.0 with the first tagged release; until then everything is under Unreleased.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added

- The APV product-line pack Circle built is merged onto the exemplar.
- APV product line: five tool modules, three `hub-hook/1` handlers, and declarations.
- The dependency boundary for pack tool implementations is stated.
- The product-line pack exemplar, with APV's four capabilities as the worked example.
- `modules.json` lists each module with its files and digest for circle-hub's installer.
- apv-mindmap-compile 0.2.4, the version Circle produced and an approver accepted, with tests of its evidence format.
- The APV mindmap compile skill.

### Changed

- Workbook tests use documentation addresses.
- Host destructive-command patterns are limited to real self-destruction, and deployment addresses stay out of tests.
- Packs name circle-hub as the platform they are installed on.
- apv-mindmap-compile 0.2.7 publishes the build-binding change. The accepted trial covers both binding paths.
- Uploaded command sources bind by their sar id, and the workbook shows the declared build name.
- Client rows are checked against the registered Excel function contract, and the skill no longer keeps product facts.
