# Original role: ticket

- File: UTF-8 JSON `{tickets:[{id, subject, severity, tier}]}`.
- `severity` is 1, 2, 3 or 4. `tier` is `standard`, `priority` or `contract`.
- Metadata to declare at upload: `queue` (a synthetic label such as `example-support`).
- Reply drafts are model judgement. The priority is a script. Knowledge-base sections come from the documents connector, not from this file.
