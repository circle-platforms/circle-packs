# Original role: contract

- File: one supplier contract as UTF-8 text. Headings are Markdown (`# Heading`) or numbered (`1. Heading`).
- Required headings the script looks for: Payment terms, Termination, Liability, Data protection.
- Metadata to declare at upload: `supplier` (a synthetic label such as `example-supplier`), `period`.
- Who uploads: the person running the review. The hub stores the bytes and the SHA. This repository does not.
- The tool reads the bytes only after an independent reviewer has approved the original.
