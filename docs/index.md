# circle-packs documentation

Skill packs and product-line packs installed on [circle-hub](https://circle-platforms.github.io/circle-hub/), the team hub for [Circle](https://circle-platforms.github.io/circle/). Each module has its own version and is installed through circle-hub's own mechanism: a pack is pushed, a trial is recorded, and an independent reviewer approves it. The modules, the checks and the module list are described in the [README](https://github.com/circle-platforms/circle-packs#readme) on GitHub.

## The three repositories

[circle](https://circle-platforms.github.io/circle/) is the agent, [circle-hub](https://circle-platforms.github.io/circle-hub/) is the hub it signs in to, and circle-packs holds the packs installed on the hub.
